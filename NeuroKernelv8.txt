NeuroKernel v8 — Hardened Autonomy

Radiation-Hardened Neuromorphic SoC with Temporal Diversity, Physical Bus Amputation, and Self-Distilling Recovery

The v8 Mantra: "The OS is not just running on the hardware; it is constantly re-proving the hardware's existence."

This document represents NeuroKernel v8, integrating all v8 improvements onto the v7 baseline.
The evolution shifts from "Graceful Reconfiguration" (v7) to "Hardened Autonomy" — the system no longer merely flows around damage; it immunises itself against correlated failures, babbling peripherals, and stack-level attacks while building a unique cryptographic identity from its own scars.

All v7 changes are preserved. New v8 additions are tagged [V8: X-Y] mapping directly to the v8 improvement log.

Overview of Changes (v8 additions)

nk-muk/src/hw/shadow_stack.rs (new — [V8: 2-A])

//! XOR-Linked Shadow Stack. //! //! [V8: 2-A] Return addresses are stored as `RA ^ Random_Nonce` in a //! dedicated shadow stack region. Before a function returns, the //! kernel XORs back using the stored nonce and compares the result //! to the value on the real stack. A bit-flip in either copy //! produces a mismatched address, triggering a controlled exception //! rather than jumping to random memory. //! //! Design notes //! ───────────── //! * The nonce is a 64-bit value written once per task during creation, sourced //! from the hardware entropy seed XORed with the task's PID and epoch. //! * The shadow entries are stored in a separate SRAM region (SHADOW_STACK_RA_BASE) //! protected by a dedicated PMP entry — distinct from the real stack region — //! so a single radiation event cannot corrupt both simultaneously. //! * In a full RTOS integration, the compiler is configured to emit calls to //! `__shadow_push` / `__shadow_pop` as function entry/exit instrumentation //! (analogous to `-fstack-protector-strong` but spatially separated). use core::sync::atomic::{AtomicU64, Ordering}; use crate::consts::{ SHADOW_STACK_NONCE_BASE, SHADOW_STACK_RA_BASE, SHADOW_STACK_DEPTH, BOOT_ENTROPY_SEED, }; /// Per-task shadow stack state, kept in the kernel's private data region. pub struct ShadowStack { /// XOR nonce unique to this task. pub nonce: u64, /// Depth of the shadow stack (number of currently pushed frames). pub depth: usize, } impl ShadowStack { /// Initialise a shadow stack for `task_pid` at `epoch`. /// /// The nonce is derived deterministically but uniquely per (pid, epoch) pair. pub fn new(task_pid: u32, epoch: u32) -> Self { // Mix PID, epoch, and the boot entropy seed into a unique nonce. let nonce = BOOT_ENTROPY_SEED ^ ((task_pid as u64) << 32) ^ (epoch as u64) ^ 0xC0FFEE_DEADBEEF_u64.rotate_left(17); // Write the nonce into the MMIO-mapped nonce table so the ASIC can // verify it independently on every function return (hardware assist). unsafe { let slot = task_pid as usize % SHADOW_STACK_DEPTH; core::ptr::write_volatile(SHADOW_STACK_NONCE_BASE.add(slot), nonce); } Self { nonce, depth: 0 } } /// Called at function entry: encode `return_address` with the nonce and /// push the encoded value onto the shadow stack. /// /// # Safety /// Must be called in M-mode with interrupts disabled during the push /// to prevent a TOCTOU race between push and the shadow write. #[inline(always)] pub unsafe fn push(&mut self, return_address: usize, task_pid: u32) -> Result<(), ()> { if self.depth >= SHADOW_STACK_DEPTH { return Err(()); } let encoded = (return_address as u64) ^ self.nonce; let slot_base = (task_pid as usize % SHADOW_STACK_DEPTH) * SHADOW_STACK_DEPTH; core::ptr::write_volatile( SHADOW_STACK_RA_BASE.add(slot_base + self.depth), encoded, ); self.depth += 1; Ok(()) } /// Called at function exit: pop the encoded return address, decode it, /// and compare against the value on the real hardware stack. /// /// Returns `Ok(verified_ra)` on match, or `Err(())` if a bit-flip /// (or intentional overwrite) is detected — the caller must treat this /// as a fatal control-flow integrity violation. #[inline(always)] pub unsafe fn pop_and_verify( &mut self, real_stack_ra: usize, task_pid: u32, ) -> Result<usize, ()> { if self.depth == 0 { return Err(()); } self.depth -= 1; let slot_base = (task_pid as usize % SHADOW_STACK_DEPTH) * SHADOW_STACK_DEPTH; let encoded = core::ptr::read_volatile( SHADOW_STACK_RA_BASE.add(slot_base + self.depth), ); let decoded = (encoded ^ self.nonce) as usize; if decoded != real_stack_ra { // Divergence: either the shadow was flipped (radiation) or the real // stack was overwritten (corruption). Either way, refuse the return. return Err(()); } Ok(decoded) } /// Flush the entire shadow stack on a context switch or task termination. pub unsafe fn flush(&mut self, task_pid: u32) { let slot_base = (task_pid as usize % SHADOW_STACK_DEPTH) * SHADOW_STACK_DEPTH; for i in 0..SHADOW_STACK_DEPTH { core::ptr::write_volatile(SHADOW_STACK_RA_BASE.add(slot_base + i), 0u64); } self.depth = 0; } } /// Global array of per-task shadow stacks (kernel-owned, PMP-protected). /// Indexed by `task_pid % SHADOW_STACK_DEPTH`. pub static mut SHADOW_STACKS: [Option<ShadowStack>; 64] = { const NONE: Option<ShadowStack> = None; [NONE; 64] }; /// Convenience: look up or initialise the shadow stack for `task_pid`. pub unsafe fn get_or_create(task_pid: u32, epoch: u32) -> &'static mut ShadowStack { let slot = task_pid as usize % 64; if SHADOW_STACKS[slot].is_none() { SHADOW_STACKS[slot] = Some(ShadowStack::new(task_pid, epoch)); } SHADOW_STACKS[slot].as_mut().unwrap() }
