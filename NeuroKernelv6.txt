NeuroKernel v6 — Fully Integrated Codebase

Radiation-Hardened Neuromorphic SoC with Formally-Verified Microkernel Substrate

This represents NeuroKernel v6, integrating all improvements from the v6 improvement log onto the v5 baseline. The improvements focus on deterministic recovery, hardware-software co-assurance, and higher-order statistical integrity.

All v5 changes are preserved. New v6 additions are tagged [V6: X-Y] mapping directly to the improvement log.

Overview of Changes (v6 additions)

//! RISC-V Physical Memory Protection (PMP) CSR management. //! //! [V4: 2-A] Added Lock bit (L-bit) support and multi-region programming. //! [V5: 2-A] PMP Context Shadowing and Verification. Defends against SEUs //! altering CSR configurations between context switches. //! [V6: 2-B] Atomic PMP Shadowing — shadow state now uses AtomicUsize fields, //! preventing torn reads/writes across cores and interrupt handlers. //! [V6: 2-A] verify_pmp_shadow() exposed for periodic tick-level CSR scrubbing. use core::sync::atomic::{AtomicUsize, Ordering}; use crate::consts::PMP_REGION_COUNT; // ── Permission helpers ───────────────────────────────────────────────────────── #[derive(Clone, Copy, PartialEq)] pub struct PmpPerms { pub read: bool, pub write: bool, pub execute: bool, pub locked: bool, } impl PmpPerms { pub const RW: Self = Self { read: true, write: true, execute: false, locked: false }; pub const RO_X_LOCKED: Self = Self { read: true, write: false, execute: true, locked: true }; pub const RW_LOCKED: Self = Self { read: true, write: true, execute: false, locked: true }; pub const NONE: Self = Self { read: false, write: false, execute: false, locked: false }; } #[derive(Clone, Copy)] #[repr(u8)] pub enum PmpMatch { Off = 0b00, Napot = 0b11, } // ── [V6: 2-B] Atomic Shadow State ───────────────────────────────────────────── // // V5 used a plain `[PmpShadow; 8]` behind `static mut`, which required `unsafe` // for every access and was susceptible to torn reads on multi-core or // interrupt-preempted paths. V6 replaces it with a struct of AtomicUsize fields // so both addr and cfg are independently visible without locks. struct PmpShadowAtomic { addr: AtomicUsize, cfg: AtomicUsize, } impl PmpShadowAtomic { const fn new() -> Self { Self { addr: AtomicUsize::new(0), cfg: AtomicUsize::new(0), } } } // SAFETY: AtomicUsize is Send + Sync; no interior mutability hazard. static PMP_SHADOW: [PmpShadowAtomic; 8] = [ PmpShadowAtomic::new(), PmpShadowAtomic::new(), PmpShadowAtomic::new(), PmpShadowAtomic::new(), PmpShadowAtomic::new(), PmpShadowAtomic::new(), PmpShadowAtomic::new(), PmpShadowAtomic::new(), ]; // ── Public API ───────────────────────────────────────────────────────────────── /// Program a NAPOT PMP region and record it atomically in the shadow state. pub unsafe fn set_napot(n: usize, base: usize, size: usize, perms: PmpPerms) { debug_assert!(n < 8, "PMP index out of range"); let napot_addr = (base >> 2) | ((size >> 3) - 1); let mut cfg_byte: u8 = (PmpMatch::Napot as u8) << 3; if perms.read { cfg_byte |= 1; } if perms.write { cfg_byte |= 2; } if perms.execute { cfg_byte |= 4; } if perms.locked { cfg_byte |= 0x80; } // [V6: 2-B] Store shadow atomically before touching hardware. PMP_SHADOW[n].addr.store(napot_addr, Ordering::Release); PMP_SHADOW[n].cfg .store(cfg_byte as usize, Ordering::Release); // Program hardware CSRs. write_pmpaddr(n, napot_addr); update_pmpcfg(n, cfg_byte); // Immediate read-back verification (catches write-time upsets). if read_pmpaddr(n) != napot_addr { panic!("PMP SET FAULT: Hardware CSR mismatch on write (Radiation Upset?)"); } } /// Clear unlocked grant region (index 3) and update shadow atomically. pub unsafe fn clear_all_unlocked() { PMP_SHADOW[3].addr.store(0, Ordering::Release); PMP_SHADOW[3].cfg .store(0, Ordering::Release); write_pmpaddr(3, 0); update_pmpcfg(3, 0x00); } /// [V6: 2-A] Periodic CSR verification — compare live hardware against shadow. /// /// Called from `tick()` at every timer interrupt. If any region drifts from its /// shadow (indicating a mid-execution SEU in a CSR), the kernel immediately /// triggers a warm-reboot panic because the security boundary is physically /// compromised. pub unsafe fn verify_pmp_shadow() { for n in 0..8 { let shadow_addr = PMP_SHADOW[n].addr.load(Ordering::Acquire); let shadow_cfg = PMP_SHADOW[n].cfg .load(Ordering::Acquire); let hw_addr = read_pmpaddr(n); let hw_cfg = read_pmpcfg(n) as usize; if hw_addr != shadow_addr || hw_cfg != shadow_cfg { // Security boundary physically compromised mid-execution. panic!( "PMP PERIODIC SCRUB FAULT: CSR mismatch on region {} \ (addr hw={:#x} shadow={:#x}, cfg hw={:#x} shadow={:#x}). \ Triggering warm reboot.", n, hw_addr, shadow_addr, hw_cfg, shadow_cfg ); } } } // ── CSR low-level stubs ──────────────────────────────────────────────────────── // (Full asm implementations use csrw/csrr for pmpaddrN and pmpcfgN.) unsafe fn write_pmpaddr(n: usize, val: usize) { // arch: csrw pmpaddr{n}, val let _ = (n, val); } unsafe fn update_pmpcfg(n: usize, cfg: u8) { // arch: read-modify-write pmpcfg{n/4}, inserting cfg into the correct byte let _ = (n, cfg); } unsafe fn read_pmpaddr(n: usize) -> usize { // arch: csrr pmpaddr{n} let _ = n; 0 } unsafe fn read_pmpcfg(n: usize) -> u8 { // arch: csrr pmpcfg{n/4}, extract byte let _ = n; 0 }

//! EDF scheduler with O(log N) binary heap and Deadline Inheritance. //! //! [V4: 2-C] EDF Deadline Inheritance. //! [V5: 1-C] Hardware Monitor Heartbeat. //! [V5: 3-A] Execution Budget Enforcement (soft: deadline push-out). //! [V5: 3-B] Mixed-Criticality modes. //! [V6: 2-A] Periodic CSR Scrubbing in tick(). //! [V6: 2-C] Hard Budget Quarantine — tasks exceeding budget by >20% are //! Suspended and only released at a Low-Power/Maintenance epoch. use heapless::binary_heap::{BinaryHeap, Min}; use core::sync::atomic::{AtomicU32, Ordering}; use spin::Mutex; use crate::hw::pmp; use crate::consts::{BUDGET_OVERRUN_PENALTY_NS, BUDGET_QUARANTINE_FRACTION}; const NO_TASK: u32 = u32::MAX; const HW_HEARTBEAT_REG: *mut u32 = 0x4000_1000 as *mut u32; pub static CURRENT_TASK_PID: AtomicU32 = AtomicU32::new(NO_TASK); pub static GLOBAL_EPOCH: AtomicU32 = AtomicU32::new(1); // [V5: 2-B] // ── Task State ───────────────────────────────────────────────────────────────── #[derive(Eq, PartialEq, Clone, Copy, Debug)] pub enum Criticality { Low, High } // [V5: 3-B] /// [V6: 2-C] Task lifecycle — extends the original Active/Pending model. #[derive(Eq, PartialEq, Clone, Copy, Debug)] pub enum TaskState { Active, /// Quarantined after a severe budget overrun (>20%). Released only during /// a Low-Power or Maintenance epoch by `release_quarantined_tasks()`. Suspended, } #[derive(Eq, PartialEq, Clone)] pub struct Task { pub pid: u32, pub criticality: Criticality, pub state: TaskState, // [V6: 2-C] pub base_deadline_ns: u64, pub eff_deadline_ns: u64, pub budget_ns: u64, pub exec_time_ns: u64, // [V5: 3-A] Tracker for budget enforcement pub token_version: u32, // [V5: 2-B] Ties task to capability epoch pub shadow_canary: u64, // [V5: 2-C] Generated dynamically per-boot pub code_base: usize, pub data_base: usize, } impl Ord for Task { fn cmp(&self, other: &Self) -> core::cmp::Ordering { // [V6: 2-C] Suspended tasks sort to the bottom regardless of deadline. match (&self.state, &other.state) { (TaskState::Suspended, TaskState::Active) => core::cmp::Ordering::Less, (TaskState::Active, TaskState::Suspended) => core::cmp::Ordering::Greater, _ => { // [V5: 3-B] High criticality always beats Low within same state. match (&self.criticality, &other.criticality) { (Criticality::High, Criticality::Low) => core::cmp::Ordering::Greater, (Criticality::Low, Criticality::High) => core::cmp::Ordering::Less, _ => other.eff_deadline_ns.cmp(&self.eff_deadline_ns), // EDF } } } } } impl PartialOrd for Task { fn partial_cmp(&self, other: &Self) -> Option<core::cmp::Ordering> { Some(self.cmp(other)) } } // ── Scheduler ───────────────────────────────────────────────────────────────── struct Scheduler { tasks: BinaryHeap<Task, Min, 64>, epoch_mode: EpochMode, // [V6: 2-C] } /// [V6: 2-C] System epoch modes that gate quarantine release. #[derive(Eq, PartialEq, Clone, Copy)] pub enum EpochMode { Normal, LowPower, Maintenance, } static SCHEDULER: Mutex<Scheduler> = Mutex::new(Scheduler { tasks: BinaryHeap::new(), epoch_mode: EpochMode::Normal, }); // ── tick() — called from timer interrupt ────────────────────────────────────── pub fn tick(elapsed_ns: u64) { // [V5: 1-C] Feed the Redundant Hardware Monitor FSM. unsafe { core::ptr::write_volatile(HW_HEARTBEAT_REG, 1); } // [V6: 2-A] Periodic CSR scrubbing — verify PMP registers against shadow. // If a mismatch is detected here (mid-task execution), panic immediately; // the hardware security boundary has been physically compromised. unsafe { pmp::verify_pmp_shadow(); } let mut sched = SCHEDULER.lock(); // ── Budget enforcement ──────────────────────────────────────────────────── if let Some(mut current) = sched.tasks.peek_mut() { current.exec_time_ns += elapsed_ns; let quarantine_threshold = current.budget_ns .saturating_mul(BUDGET_QUARANTINE_FRACTION) / 100; if current.exec_time_ns >= quarantine_threshold { // [V6: 2-C] Hard quarantine: task has blown >20% past its budget. // Mark Suspended — it will not be dispatched until the system enters // a LowPower or Maintenance epoch. current.state = TaskState::Suspended; current.exec_time_ns = 0; } else if current.exec_time_ns >= current.budget_ns { // [V5: 3-A] Soft enforcement: push deadline, reset accumulator. current.eff_deadline_ns += BUDGET_OVERRUN_PENALTY_NS; current.exec_time_ns = 0; } } // ── Context switch ──────────────────────────────────────────────────────── // Skip Suspended tasks — peek the first Active one. let next_active = sched.tasks.iter().find(|t| t.state == TaskState::Active); if let Some(task) = next_active { CURRENT_TASK_PID.store(task.pid, Ordering::Release); unsafe { pmp::clear_all_unlocked(); pmp::set_napot(0, task.code_base, 0x10000, pmp::PmpPerms::RO_X_LOCKED); pmp::set_napot(1, task.data_base, 0x10000, pmp::PmpPerms::RW_LOCKED); } // Install shadow-stack canary. const SHADOW_STACK_BASE: *mut u64 = 0x2000_F000 as *mut u64; unsafe { core::ptr::write_volatile( SHADOW_STACK_BASE.add(task.pid as usize % 64), task.shadow_canary, ); } } else { CURRENT_TASK_PID.store(NO_TASK, Ordering::Release); unsafe { pmp::clear_all_unlocked(); } } } // ── [V6: 2-C] Quarantine release ───────────────────────────────────────────── /// Called when the system transitions into `LowPower` or `Maintenance` epoch. /// Releases all `Suspended` tasks back into the Active queue so they can /// eventually be re-scheduled, preventing permanent starvation. pub fn enter_epoch(mode: EpochMode) { let mut sched = SCHEDULER.lock(); sched.epoch_mode = mode; if mode == EpochMode::LowPower || mode == EpochMode::Maintenance { // Reconstruct heap with all Suspended tasks promoted back to Active. // heapless::BinaryHeap does not support iteration with mutation, so // we drain into a temp buffer, mutate, and re-insert. let mut buf: heapless::Vec<Task, 64> = heapless::Vec::new(); while let Some(t) = sched.tasks.pop() { let _ = buf.push(t); } for mut t in buf { if t.state == TaskState::Suspended { t.state = TaskState::Active; // Assign a far-future deadline so it runs last in the epoch. t.eff_deadline_ns = u64::MAX; } let _ = sched.tasks.push(t); } } } // ── Deadline Inheritance [V4: 2-C] ──────────────────────────────────────────── pub fn inherit_deadline(holder_pid: u32, waiter_deadline: u64) { let mut sched = SCHEDULER.lock(); let mut buf: heapless::Vec<Task, 64> = heapless::Vec::new(); while let Some(t) = sched.tasks.pop() { let _ = buf.push(t); } for mut t in buf { if t.pid == holder_pid && t.eff_deadline_ns > waiter_deadline { t.eff_deadline_ns = waiter_deadline; } let _ = sched.tasks.push(t); } }

//! Grant-based zero-copy IPC with Seqlock protection. //! //! [V5: 1-D] Lightweight checksumming on IPC headers (FNV-1a). //! [V5: 2-B] Capability versioning bounds via Token Epochs. //! [V6: 3-A] Upgrade to CRC-32-C (Castagnoli) for burst-error resilience. //! [V6: 3-B] Epoch Fence Zeroing — on GLOBAL_EPOCH increment, any In-Flight //! SharedRegionHeader is zeroed so a compromised task cannot finish //! a write from a now-revoked epoch. use core::sync::atomic::{AtomicU32, Ordering}; use crate::consts::SHARED_MEM_REGION_BYTES; use crate::scheduler::GLOBAL_EPOCH; // ── IPC State ───────────────────────────────────────────────────────────────── /// A sentinel stored in `in_flight_epoch` when no write is in progress. const EPOCH_IDLE: u32 = 0; #[repr(C)] pub struct SharedRegionHeader { pub version: AtomicU32, pub checksum: AtomicU32, // [V6: 3-A] CRC-32-C of write metadata /// [V6: 3-B] Set to the current epoch when a write begins; cleared on commit. pub in_flight_epoch: AtomicU32, _pad: [u8; 52], } #[link_section = ".shared_mem"] static mut SHARED_MEM: [u8; SHARED_MEM_REGION_BYTES] = [0u8; SHARED_MEM_REGION_BYTES]; const HEADER_SIZE: usize = 64; #[derive(Clone, Debug)] pub struct MemoryGrantToken { pub base_offset: u32, pub length: u32, pub capability_idx: usize, pub epoch_issued: u32, // [V5: 2-B] Epoch versioning for revocation } #[inline] fn header() -> &'static SharedRegionHeader { unsafe { &*(SHARED_MEM.as_ptr() as *const SharedRegionHeader) } } // ── [V6: 3-A] CRC-32-C (Castagnoli) ───────────────────────────────────────── // // CRC-32-C is mathematically designed to detect burst errors — multiple // contiguous bit flips — which are the primary failure mode of radiation-induced // upsets on memory buses. FNV-1a (V5) detects only independent single-bit // flips. // // This is a software table-free implementation using the Castagnoli polynomial // (0x82F63B78 reflected). A hardware CRC32 instruction is available on some // RISC-V extensions; substitute that if present. const CRC32C_POLY: u32 = 0x82F63B78; pub fn crc32c(data: &[u8]) -> u32 { let mut crc: u32 = 0xFFFF_FFFF; for &byte in data { crc ^= byte as u32; for _ in 0..8 { if crc & 1 != 0 { crc = (crc >> 1) ^ CRC32C_POLY; } else { crc >>= 1; } } } !crc } // ── [V6: 3-B] Epoch Fence ───────────────────────────────────────────────────── /// Increment the global capability epoch and zero any In-Flight write. /// /// Must be called whenever a security violation is detected (e.g. a PMP fault, /// a capability revocation, or a task entering quarantine). Any write that was /// started before the epoch increment is irrevocably cancelled: its header is /// zeroed, so readers will see a stale seqlock version and retry from a clean /// state. pub fn advance_epoch_with_fence() { // Bump the epoch atomically. GLOBAL_EPOCH.fetch_add(1, Ordering::AcqRel); // Zero any In-Flight write header. let h = header(); let in_flight = h.in_flight_epoch.load(Ordering::Acquire); if in_flight != EPOCH_IDLE { // The write was started in a now-revoked epoch; discard it entirely. h.version .store(0, Ordering::Release); h.checksum .store(0, Ordering::Release); h.in_flight_epoch.store(EPOCH_IDLE, Ordering::Release); // Zero the data region so no partial data leaks. unsafe { core::ptr::write_bytes( SHARED_MEM.as_mut_ptr().add(HEADER_SIZE), 0, SHARED_MEM_REGION_BYTES - HEADER_SIZE, ); } } } // ── Write path ──────────────────────────────────────────────────────────────── pub unsafe fn shared_write( offset: usize, data: &[u8], token: &MemoryGrantToken, ) -> Result<(), ()> { // [V5: 2-B] Token epoch check. let current_epoch = GLOBAL_EPOCH.load(Ordering::Acquire); if token.epoch_issued < current_epoch { return Err(()); // Revoked token. } // Bounds check. if offset.checked_add(data.len()).ok_or(())? > token.length as usize { return Err(()); } let abs_start = HEADER_SIZE + (token.base_offset as usize) + offset; let abs_end = abs_start + data.len(); if abs_end > SHARED_MEM_REGION_BYTES { return Err(()); } let h = header(); // [V6: 3-B] Mark write as In-Flight before touching data. h.in_flight_epoch.store(current_epoch, Ordering::Release); core::sync::atomic::fence(Ordering::SeqCst); // Seqlock: odd version = write in progress. let seq = h.version.fetch_add(1, Ordering::Release); SHARED_MEM[abs_start..abs_end].copy_from_slice(data); // [V6: 3-A] Compute CRC-32-C over write metadata (version + raw data). let mut crc_input = [0u8; 8 + 256]; // version (4 bytes) + up to 256 bytes data crc_input[..4].copy_from_slice(&seq.to_le_bytes()); let copy_len = data.len().min(252); crc_input[4..4 + copy_len].copy_from_slice(&data[..copy_len]); let new_crc = crc32c(&crc_input[..4 + copy_len]); h.checksum.store(new_crc, Ordering::Release); core::sync::atomic::fence(Ordering::SeqCst); // Seqlock: even version = write complete. h.version.fetch_add(1, Ordering::Release); // [V6: 3-B] Clear In-Flight marker now that the write committed cleanly. h.in_flight_epoch.store(EPOCH_IDLE, Ordering::Release); Ok(()) } // ── Read path ───────────────────────────────────────────────────────────────── pub unsafe fn shared_read( offset: usize, buf: &mut [u8], token: &MemoryGrantToken, ) -> Result<(), ()> { if token.epoch_issued < GLOBAL_EPOCH.load(Ordering::Acquire) { return Err(()); } if offset.checked_add(buf.len()).ok_or(())? > token.length as usize { return Err(()); } let abs_start = HEADER_SIZE + (token.base_offset as usize) + offset; let abs_end = abs_start + buf.len(); if abs_end > SHARED_MEM_REGION_BYTES { return Err(()); } let h = header(); // Seqlock retry loop. loop { let seq_before = h.version.load(Ordering::Acquire); if seq_before & 1 != 0 { continue; } // Writer active. buf.copy_from_slice(&SHARED_MEM[abs_start..abs_end]); core::sync::atomic::fence(Ordering::SeqCst); let seq_after = h.version.load(Ordering::Acquire); if seq_before == seq_after { break; } } Ok(()) }

// ── Status ──────────────────────────────────────────────────────────────────── #[derive(Debug, PartialEq, Clone, Copy)] pub enum FidelityStatus { Optimal, Degraded, // EWMA fallback UltraDegraded, // [V5: 4-A] Static bounds based on last known good } // ── State ───────────────────────────────────────────────────────────────────── pub struct FidelityState { pub count: u64, pub m2: U16F48, pub status: FidelityStatus, pub ewma_mean: U0F64, pub ewma_var: U0F64, pub confidence: u32, // [V5: 4-A] Telemetry confidence score pub last_known_var: U16F48, // [V6: 4-B] Holt-Winters trend component. // `trend` estimates the rate of change of ewma_var per observation. // Stored as U0F64 (unsigned, so only rising trends are tracked — sufficient // for radiation monitoring where we care about intensity increases). pub hw_trend: U0F64, // [V6: 4-A] Count of consecutive clean (non-anomaly) observations for // recovery pacing. clean_streak: u64, } impl FidelityState { pub fn new() -> Self { Self { count: 0, m2: U16F48::from_bits(0), status: FidelityStatus::Optimal, ewma_mean: U0F64::from_bits(0), ewma_var: U0F64::from_bits(0), confidence: CONFIDENCE_BASE, last_known_var: U16F48::from_bits(0), hw_trend: U0F64::from_bits(0), clean_streak: 0, } } // ── Fault notification ──────────────────────────────────────────────────── pub fn mark_hardware_anomaly(&mut self) { // [V5: 4-A] Faults directly impact statistical confidence. self.confidence = self.confidence.saturating_sub(CONFIDENCE_PENALTY_PER_FAULT); self.clean_streak = 0; // [V6: 4-A] Reset recovery streak. if self.confidence < (CONFIDENCE_BASE / 4) { self.status = FidelityStatus::UltraDegraded; } } // ── [V6: 4-A] Recovery path ─────────────────────────────────────────────── /// Call once per observation cycle when *no* anomaly was detected. /// /// Slowly rebuilds confidence after 1000 consecutive clean observations, /// and transitions back to `Optimal` once confidence crosses the threshold. pub fn step_recovery(&mut self) { if self.status == FidelityStatus::Optimal { return; // Nothing to recover. } self.clean_streak = self.clean_streak.saturating_add(1); // Increment confidence every CONFIDENCE_RECOVERY_INTERVAL clean ticks. if self.clean_streak % CONFIDENCE_RECOVERY_INTERVAL == 0 { self.confidence = self.confidence.saturating_add(CONFIDENCE_RECOVERY_STEP); } // Promote back to Optimal once confidence is sufficiently restored. if self.confidence >= CONFIDENCE_OPTIMAL_THRESHOLD { self.status = FidelityStatus::Optimal; // Do NOT reset clean_streak — keep accumulating for telemetry. } } // ── [V6: 4-B] Holt-Winters update ──────────────────────────────────────── /// Update the trend component with the latest EWMA variance observation. /// /// Uses double exponential smoothing (Holt-Winters without seasonality): /// trend(t) = β * (ewma_var(t) − ewma_var(t−1)) + (1−β) * trend(t−1) /// /// Returns `true` if the predicted next variance exceeds the trigger /// threshold, meaning `Degraded` mode should be entered pre-emptively. fn update_trend_and_predict(&mut self, prev_var: U0F64) -> bool { let beta = U0F64::from_bits(HW_BETA_BITS); let one_m_beta = U0F64::from_bits(!0u64 - HW_BETA_BITS); // Delta = current − previous variance (saturate at 0 if decreasing). let delta = if self.ewma_var > prev_var { self.ewma_var - prev_var } else { U0F64::from_bits(0) }; // trend = β * delta + (1−β) * trend self.hw_trend = delta.saturating_mul(beta) .saturating_add(self.hw_trend.saturating_mul(one_m_beta)); // Predicted next variance = ewma_var + trend. let predicted = self.ewma_var.saturating_add(self.hw_trend); // Trigger if predicted exceeds current by the multiplier. // Multiply ewma_var by HW_TREND_TRIGGER_MULTIPLIER via repeated add. let mut threshold = self.ewma_var; for _ in 1..HW_TREND_TRIGGER_MULTIPLIER { threshold = threshold.saturating_add(self.ewma_var); } predicted >= threshold } // ── Main update ─────────────────────────────────────────────────────────── pub fn update_welford(&mut self, obs: U0F64) { let alpha = U0F64::from_bits(EWMA_ALPHA_BITS); let one_m_alpha = U0F64::from_bits(!0u64 - EWMA_ALPHA_BITS); let diff = if obs > self.ewma_mean { obs - self.ewma_mean } else { self.ewma_mean - obs }; self.ewma_mean = self.ewma_mean .saturating_mul(one_m_alpha) .saturating_add(obs.saturating_mul(alpha)); let prev_var = self.ewma_var; let diff_sq = diff.saturating_mul(diff); self.ewma_var = self.ewma_var .saturating_mul(one_m_alpha) .saturating_add(diff_sq.saturating_mul(alpha)); // [V6: 4-B] Check trend prediction before further state evaluation. if self.status == FidelityStatus::Optimal { let trend_danger = self.update_trend_and_predict(prev_var); if trend_danger { // Pre-emptively enter Degraded; radiation intensity is rising. self.status = FidelityStatus::Degraded; self.confidence /= 2; return; } } if self.status == FidelityStatus::UltraDegraded { return; } if self.status == FidelityStatus::Optimal { self.count = self.count.saturating_add(1); let contribution = U16F48::from_bits(1000); match self.m2.checked_add(contribution) { Some(new_m2) => { self.m2 = new_m2; self.last_known_var = U16F48::from_bits(self.m2.to_bits() / self.count); } None => { // Saturation → Degraded. self.status = FidelityStatus::Degraded; self.confidence /= 2; } } } } // ── Variance accessor ───────────────────────────────────────────────────── /// Returns `(variance, confidence)`. pub fn variance(&self) -> (U16F48, u32) { match self.status { FidelityStatus::Optimal => { if self.count < 2 { return (U16F48::from_bits(0), self.confidence); } ( U16F48::from_bits(self.m2.to_bits() / (self.count - 1)), self.confidence, ) } FidelityStatus::Degraded => { let ewma_bits = self.ewma_var.to_bits(); (U16F48::from_bits((ewma_bits >> 16) as u64), self.confidence) } FidelityStatus::UltraDegraded => { // Return last known good with heavily penalised confidence. (self.last_known_var, self.confidence) } } } }
