NeuroKernel v7 — Fully Integrated Codebase

Radiation-Hardened Neuromorphic SoC with Graceful Reconfiguration and Spatial Intelligence

This document represents NeuroKernel v7, integrating all improvements from the v7 improvement log onto the v6 baseline. The evolution shifts from "Deterministic Recovery" (v6) toward "Graceful Reconfiguration and Spatial Intelligence" — the system no longer reboots around faults; it flows around them.

All v6 changes are preserved. New v7 additions are tagged [V7: X-Y] mapping directly to the improvement log.

Overview of Changes (v7 additions)

LayerNew ImprovementVerilog / ASIC[V7: 1-A] Hard-Wired Shadow CSR Registers — ASIC detects CSR mismatch and auto-restores, firing an interrupt instead of forcing a kernel panic.Verilog / ASIC[V7: 1-B] Stuck-at Fault Discrimination — if ECC corrects the same bit address 3× despite scrubbing, that sector is flagged as permanently damaged and exported to the kernel.Rust / kernel[V7: 2-A] Radiation-Aware Memory Allocation — alloc() queries the ASIC heat map; high-criticality task data is steered to "cold" (low-SEU) sectors.Rust / kernel[V7: 2-B] Dynamic Software TMR / "Storm Mode" — Holt-Winters trend prediction triggers the scheduler to spawn 3 task replicas and majority-vote outputs during predicted radiation peaks.Rust / fidelity[V7: 3-A] Weight Refresh via Golden Image — the UltraDegraded FSM trigger initiates a DMA transfer of Golden Weights from MRAM/ROM to active SRAM.Rust / fidelity[V7: 3-B] Bayesian Confidence Filter — upgrades Holt-Winters to incorporate external dosimeter readings, updating a belief distribution over hardware reliability.Rust / IPC[V7: 4-A] Reed-Solomon Forward Error Correction — IPC buffers are RS(255,223) encoded; receivers reconstruct data without retransmission after burst events.Rust / IPC[V7: 4-B] Dual-Write Pointer Ghosting Prevention — IPC handles stored in two independent memory banks; cross-referenced before every dereference.Formal / TLA+[V7: 5-A] Graceful Dismantling — proves the system meets Minimum Viable Safety deadlines even with 50% of CNN filters blacklisted.Formal / TLA+[V7: 5-B] Non-Interference under Faults — proves a Low-Criticality failure cannot prevent a High-Criticality task from reaching WarmReboot.

//! Physical Memory Protection (PMP) register management. //! //! [V6: 2-B] Atomic PMP Shadow State — shadow registers use AtomicUsize, //! preventing race conditions across cores and interrupt preemption. use core::sync::atomic::{AtomicUsize, Ordering}; #[derive(Clone, Copy, PartialEq, Eq, Debug)] pub struct PmpPerms(u8); impl PmpPerms { pub const RO_X_LOCKED: Self = Self(0b1_00_101); // L | X | R pub const RW_LOCKED: Self = Self(0b1_00_011); // L | W | R pub const NONE: Self = Self(0b1_00_000); // L only (no perms) } /// [V6: 2-B] Atomic shadow of up to 8 PMP entries. /// Each entry packs: (pmpaddr << 8) | pmpcfg_byte. struct PmpShadowAtomic { entries: [AtomicUsize; 8], } impl PmpShadowAtomic { const fn new() -> Self { const Z: AtomicUsize = AtomicUsize::new(0); Self { entries: [Z, Z, Z, Z, Z, Z, Z, Z] } } fn store(&self, idx: usize, addr: usize, perms: PmpPerms) { let packed = (addr << 8) | (perms.0 as usize); self.entries[idx].store(packed, Ordering::Release); } fn load(&self, idx: usize) -> (usize, u8) { let packed = self.entries[idx].load(Ordering::Acquire); ((packed >> 8), (packed & 0xFF) as u8) } } static PMP_SHADOW: PmpShadowAtomic = PmpShadowAtomic::new(); /// Programs a NAPOT PMP entry and updates the atomic shadow. /// /// # Safety /// Must be called from M-mode or with PMP write privileges. pub unsafe fn set_napot( idx: usize, base: usize, size: usize, perms: PmpPerms, ) { debug_assert!(idx < 8); debug_assert!(size.is_power_of_two() && size >= 8); let napot_addr = (base | (size / 2 - 1)) >> 2; let cfg_byte = perms.0 | 0b11 << 3; // A[1:0] = NAPOT // Write the physical CSR. core::arch::asm!( "csrw pmpcfg0, {cfg}", "csrw pmpaddr0, {addr}", cfg = in(reg) (cfg_byte as usize) << (8 * idx), addr = in(reg) napot_addr, ); // Mirror to the atomic shadow. PMP_SHADOW.store(idx, napot_addr, perms); } pub unsafe fn clear_all_unlocked() { for i in 0..8usize { let (_, cfg) = PMP_SHADOW.load(i); if cfg & 0b1000_0000 == 0 { PMP_SHADOW.store(i, 0, PmpPerms::NONE); } } } /// [V6: 2-A] Verify all non-LOCKED PMP registers match their atomic shadow. /// /// Called from `tick()` mid-execution. A mismatch means the CSR was flipped /// by a radiation event; panic immediately to prevent silent memory breakout. pub unsafe fn verify_pmp_shadow() { for i in 0..8usize { let (shadow_addr, _) = PMP_SHADOW.load(i); let hw_addr: usize; core::arch::asm!("csrr {out}, pmpaddr0", out = out(reg) hw_addr); if hw_addr != shadow_addr { panic!("PMP CSR mismatch on entry {}: hw={:#x} shadow={:#x}", i, hw_addr, shadow_addr); } } }

//! Radiation-Aware Spatial Memory Allocator. //! //! [V7: 2-A] Queries the ASIC heat map (exported via MMIO) and steers //! High-Criticality task allocations to "Cold" memory sectors, //! avoiding regions with elevated SEU rates. use crate::consts::{ SRAM_NUM_SECTORS, SRAM_SECTOR_SIZE_BYTES, SRAM_TOTAL_SIZE_BYTES, SECTOR_HEAT_THRESHOLD, }; /// MMIO base address of the sector heat map array (32 x 1-byte registers, /// one per sector, mirroring the Verilog `sector_heat[]` counters). const HEAT_MAP_MMIO_BASE: *const u8 = 0x4000_2000 as *const u8; /// MMIO register indicating blacklisted sectors (bit-mask, [V7: 1-B]). const STUCK_AT_MASK_REG: *const u32 = 0x4000_2020 as *const u32; /// A minimal free-list allocator that is sector-aware. /// In a real deployment this wraps the platform allocator (e.g. `talc` or /// `linked_list_allocator`) with a sector-steering front-end. pub struct SpatialAllocator { /// Per-sector free-list heads (each entry = offset within sector, or !0 if full). sector_free: [usize; SRAM_NUM_SECTORS], } impl SpatialAllocator { pub const fn new() -> Self { Self { sector_free: [0usize; SRAM_NUM_SECTORS] } } /// Read the current heat value for a sector from the ASIC MMIO map. /// /// # Safety /// Reads from a memory-mapped I/O region; must not be reordered. unsafe fn sector_heat(sector: usize) -> u8 { core::ptr::read_volatile(HEAT_MAP_MMIO_BASE.add(sector)) } /// Read the stuck-at blacklist bitmask from the ASIC. unsafe fn stuck_at_mask() -> u32 { core::ptr::read_volatile(STUCK_AT_MASK_REG) } /// Allocate `size` bytes. /// /// - `high_criticality`: if true, only sectors below `SECTOR_HEAT_THRESHOLD` /// and not in the stuck-at mask are eligible. /// - If no cold sector has room, falls back to the least-hot eligible sector. /// /// Returns a raw pointer into the SRAM region, or `None` if OOM. pub unsafe fn alloc( &mut self, size: usize, high_criticality: bool, ) -> Option<*mut u8> { if size == 0 || size > SRAM_SECTOR_SIZE_BYTES { return None; // Oversized allocations not handled here. } let stuck_mask = Self::stuck_at_mask(); // Build a ranked candidate list: prefer cold, non-blacklisted sectors. let mut best_sector: Option<usize> = None; let mut best_heat: u8 = u8::MAX; for s in 0..SRAM_NUM_SECTORS { // Skip permanently damaged sectors. if stuck_mask & (1 << s) != 0 { continue; } let heat = Self::sector_heat(s); // For high-criticality, skip sectors above the heat threshold. if high_criticality && heat >= SECTOR_HEAT_THRESHOLD { continue; } // Check if there's room in this sector. let used = self.sector_free[s]; if used + size > SRAM_SECTOR_SIZE_BYTES { continue; } if heat < best_heat { best_heat = heat; best_sector = Some(s); } } let sector = best_sector?; let offset_within_sector = self.sector_free[sector]; self.sector_free[sector] += size; // SRAM base is mapped at 0x2000_0000 in the reference SoC. const SRAM_BASE: usize = 0x2000_0000; let phys_addr = SRAM_BASE + sector * SRAM_SECTOR_SIZE_BYTES + offset_within_sector; Some(phys_addr as *mut u8) } /// Naive sector-granularity free: marks entire sector offset as reclaimed. /// A production implementation would use a proper free-list per sector. pub fn free_sector(&mut self, sector: usize) { if sector < SRAM_NUM_SECTORS { self.sector_free[sector] = 0; } } }

} } // ── [V6: 4-A] Recovery path ─────────────────────────────────────────────── pub fn step_recovery(&mut self) { if self.status == FidelityStatus::Optimal { return; } self.clean_streak = self.clean_streak.saturating_add(1); if self.clean_streak % CONFIDENCE_RECOVERY_INTERVAL == 0 { self.confidence = self.confidence.saturating_add(CONFIDENCE_RECOVERY_STEP); } if self.confidence >= CONFIDENCE_OPTIMAL_THRESHOLD { self.status = FidelityStatus::Optimal; } } // ── [V6: 4-B] + [V7: 2-B] Holt-Winters update & Storm Mode trigger ─────── /// Returns `(trend_danger, storm_trigger)`. /// `trend_danger` → enter Degraded. /// `storm_trigger` → enter Storm Mode (trend multiplier exceeds storm threshold). fn update_trend_and_predict(&mut self, prev_var: U0F64) -> (bool, bool) { let beta = U0F64::from_bits(HW_BETA_BITS); let one_m_beta = U0F64::from_bits(!0u64 - HW_BETA_BITS); let delta = if self.ewma_var > prev_var { self.ewma_var - prev_var } else { U0F64::from_bits(0) }; self.hw_trend = delta.saturating_mul(beta) .saturating_add(self.hw_trend.saturating_mul(one_m_beta)); let predicted = self.ewma_var.saturating_add(self.hw_trend); // Degrade threshold: predicted > 2 * ewma_var let mut degrade_threshold = self.ewma_var; for _ in 1..HW_TREND_TRIGGER_MULTIPLIER { degrade_threshold = degrade_threshold.saturating_add(self.ewma_var); } // [V7: 2-B] Storm threshold: predicted > STORM_MODE_TREND_MULTIPLIER * ewma_var let mut storm_threshold = self.ewma_var; for _ in 1..STORM_MODE_TREND_MULTIPLIER { storm_threshold = storm_threshold.saturating_add(self.ewma_var); } let trend_danger = predicted >= degrade_threshold; let storm_trigger = predicted >= storm_threshold; (trend_danger, storm_trigger) } // ── Main update ─────────────────────────────────────────────────────────── pub fn update_welford(&mut self, obs: U0F64) { let alpha = U0F64::from_bits(EWMA_ALPHA_BITS); let one_m_alpha = U0F64::from_bits(!0u64 - EWMA_ALPHA_BITS); let diff = if obs > self.ewma_mean { obs - self.ewma_mean } else { self.ewma_mean - obs }; self.ewma_mean = self.ewma_mean .saturating_mul(one_m_alpha) .saturating_add(obs.saturating_mul(alpha)); let prev_var = self.ewma_var; let diff_sq = diff.saturating_mul(diff); self.ewma_var = self.ewma_var .saturating_mul(one_m_alpha) .saturating_add(diff_sq.saturating_mul(alpha)); if self.status == FidelityStatus::Optimal { let (trend_danger, storm_trigger) = self.update_trend_and_predict(prev_var); // [V7: 2-B] Storm Mode management. if storm_trigger && !self.storm_active { self.storm_active = true; enter_storm_mode(); } else if !storm_trigger && self.storm_active { self.storm_active = false; exit_storm_mode(); } if trend_danger { self.status = FidelityStatus::Degraded; self.confidence /= 2; return; } } if self.status == FidelityStatus::UltraDegraded { return; } if self.status == FidelityStatus::Optimal { self.count = self.count.saturating_add(1); let contribution = U16F48::from_bits(1000); match self.m2.checked_add(contribution) { Some(new_m2) => { self.m2 = new_m2; self.last_known_var = U16F48::from_bits(self.m2.to_bits() / self.count); } None => { self.status = FidelityStatus::Degraded; self.confidence /= 2; } } } } // ── Variance accessor ───────────────────────────────────────────────────── pub fn variance(&self) -> (U16F48, u32) { match self.status { FidelityStatus::Optimal => { if self.count < 2 { return (U16F48::from_bits(0), self.confidence); } (U16F48::from_bits(self.m2.to_bits() / (self.count - 1)), self.confidence) } FidelityStatus::Degraded => { let ewma_bits = self.ewma_var.to_bits(); (U16F48::from_bits((ewma_bits >> 16) as u64), self.confidence) } FidelityStatus::UltraDegraded => (self.last_known_var, self.confidence), } } }
